# RePlanWeaver 设计文档（论文级草案 v0.1）

> 定位：**机制主张文档**，不是已实现清单。v0.1 已工程化的是 B1/B2/B4/B5/B8/B13（见主仓代码与 README 状态表）；本文展开 B3/B6/B7/B12 四条**主张**，每条附科研互证锚点、**可证伪预测**与工程映射。诚实边界：B3/B12 仅部分工程化、B6/B7 未工程化，均明确标注，不冒充已验证；口径以 README「机制状态」表为准。

---

## Abstract

多 agent 系统的失败往往不是「没做」，而是「做偏了没人发现，发现后全量重跑或无限反思」。RePlanWeaver 提出一个以**外部可验证期望**为信号源的闭环：任务卡携带 `expect{}` 契约 → 批次中途反审 → 沿依赖图圈定受污染子树 → 增量回拆 → 预算闸封顶 → 失败蒸馏回流。v0.1 以零依赖 Python 实现五机制并给出 17 例可复现测试；本文另提出四条机制主张（外部信号锚定、对偶回拆、分层验证、元反审），各附可证伪预测与置信度。**我们不主张「agent 越多越好」**，相反，Google 等 260 组配置的实证（arXiv:2512.08296）显示单 agent 准确率超过约 45% 后协作收益递减甚至为负——本工作只针对「已决定使用多 agent」之后的**过程治理**问题。

**关键词**：multi-agent systems · mid-course review · delta replanning · expectation contract · failure taxonomy

## 1 问题与立场

| 现象 | 常见做法 | 本工作立场 |
|---|---|---|
| 中间小结果偏离预期 | 让模型自己反思/重试 | 反思信号必须外部化（B3） |
| 发现偏差后修正 | 全量重跑 | 只重跑受污染子树（B4） |
| 改了还不对 | 继续改 | 预算封顶，降级交付（B5） |
| 同类错误反复出现 | 无记录 | 失败蒸馏回流（B8） |

立场基于三条科研证据：
- 步级验证优于终局验证：PRM 在 MATH 代表子集达 78.2%（arXiv:2305.20050）。
- 无外部反馈的自我纠正反而降分：GSM8K 75.9→74.7（arXiv:2310.01798）。
- 多 agent 失败有稳定分类学：MAST 从 7 框架 1600+ 轨迹归纳 14 种失败模式、3 大类，κ=0.88（arXiv:2503.13657, NeurIPS 2025 D&B Spotlight）。

## 2 已实现机制（v0.1，可复跑）

见 `replanweaver.py` §01–§06。核心数据结构：

```
TaskCard = { id, goal, expect{format,range,ground_truth}, depends_on[], status }
ExpectationContract.check(result) -> deviations[]
DriftGraph.affected(bad_ids)     -> 下游子树（BFS）
DriftGraph.replan_delta(...)     -> 只重置子树，旁支结果保留
ReplanBudget.consume()           -> ≤2 轮，耗尽即 degraded
FailureDistillery.record/prior   -> MAST 三类归档 → avoid_prior 回流
```

**实验设置**（可复现）：3 个任务，`goal=primes_sum_100`（真值 1060），T-root 拓扑下首轮注入一个错值（999）触发回拆；`--workers 4` 池化执行。结果：17/17 测试全绿、`truth_pass_rate=1.0`、`replans_used=1`、`converged=true`、`delta_saving=0.3333`。**诚实标注**：该节省率属 T-root（偏差在根且有下游），低于 50% 理想线，已按拓扑分档记入 `ACCEPTANCE.md`，未改数据。

## 3 四条机制主张（论文级）

### B3 · 外部信号锚定铁律（External-Signal Anchoring）

**主张**：任何回拆决策的触发信号，必须来自可独立复算的外部判据（真值、schema、工具返回、自动化测试）；模型对自身输出的「我觉得不对」只能作为参考，不得单独触发回拆。

**科研互证**：CRITIC（arXiv:2305.11738）用外部工具验错后修正；PRM（2305.20050）用步级外部标注；反例（2310.01798）证明无外部反馈时自纠降分。三者信号来源依次递减，效果随外部性下降。

**可证伪预测**：若在**移除** `expect.ground_truth`、仅保留模型自评的条件下，回拆后真值通过率不低于保留外部判据的条件，则 B3 被推翻（即自评足够）。当前 v0.1 未做该消融，列为 v0.5 必做实验。

**工程映射**：`ExpectationContract` 是唯一触发源；`ReviewGate` 不调用任何 LLM；`avoid_prior` 只作提示不作判决。

**与已有工作差异**：Reflexion（2303.11366）把语言反思写入记忆再重试，信号来自模型自身；Self-Refine（2303.17651）同模型单输出内自评自改。B3 明确禁止二者作为唯一信号源。

**置信度**：中高（0.75 ± 0.15）。误差来源：仅数学/格式类可机器判任务，未验证开放域写作任务。

---

### B6 · 对偶回拆（Duel Replan）

**主张**：触发回拆时，由两个独立修正案生成方（红/蓝）并行给出修正方案，中心判据器依据 `expect{}` 选优，避免单一修正路径的锚定偏差。

**科研互证**：多样性采样+投票在弱模型/难任务上有效（《More Agents Is All You Need》arXiv:2402.05120，15–20 个采样使 Llama2-13B 在 GSM8K 追平 70B）；但 2512.08296 同时指出无中心验证的独立 agent 错误放大 17.2 倍、中心化验证仅 4.4 倍——**故 B6 必须配中心判据器**，否则不成立。

**可证伪预测**：若在 ≥30 例任务上，「双修正案+判据选优」的正确率不显著高于「单修正案」（差值 <5%），或成本增幅 >2× 而收益 <5%，则 B6 不值得工程化，应删。

**工程映射**：v0.1 **未实现**（诚实标注）。拟在 `Engine` 增加 `replan_strategy=duel`，复用 `ReviewGate` 作选优判据；排队见 `PROPOSALS.md` P3。

**置信度**：中（0.55 ± 0.20）。误差来源：两条互相冲突的证据（采样有效 vs 协作负收益），需实验裁决。

---

### B7 · 分层中心验证（Tiered Central Verify）

**主张**：验证按偏差风险分三层调用——L1 规则/schema 校验（毫秒级、零成本）→ L2 判据器/真值对拍（低成本）→ L3 对抗盲评（高成本）。仅当 L1/L2 无法判决时才升 L3。

**科研互证**：PRM 步级监督（2305.20050）显示细粒度验证有效，但作者明示泛化到数学之外未验证；MAST（2503.13657）把「任务验证」列为三大失败类之一，说明验证层本身是高频失效点；2512.08296 指出工具密集型任务多 agent 协调开销更重。

**可证伪预测**：若在真实任务集上 L1+L2 已能覆盖 ≥90% 的偏差判定，且 L3 带来的额外正确率提升 <3%，则 L3 应默认关闭（分层有效）；反之若 L1 假阴性 >15%，则分层失效，须全量 L2。

**工程映射**：v0.1 只实现 L1（`ExpectationContract`）。L2/L3 未实现，标注为 v1.x 候选；`strength70_selfcheck.py` 的 F15/F16 实跑是 L1 分层的实例化。

**与已有工作差异**：PRM 需训练判分器；B7 用零成本 schema 作第一层，把昂贵验证留给少数样本，是成本-质量双约束下的工程化裁剪。

**置信度**：中（0.60 ± 0.20）。误差来源：未实测三层覆盖率。

---

### B12 · 元反审（Meta-Review of the Review Gate）

**主张**：定期审计反审机制本身，核心指标为**假阳性回拆率**（结果本已正确却被判偏差）与**误杀率**（正确结果被回拆后改错）。判据错了，越迭代越偏。

**科研互证**：2512.08296 报告架构选择可预测性能（准确率 87%），说明「元层选择」比「堆 agent 数量」更关键；MAST 的 κ=0.88 表明失败分类需要一致性检验；2310.01798 显示内在自纠会把正确答案推翻——这正是假阳性回拆的一种形态。

**可证伪预测**：若在 100 例任务上假阳性回拆率 >10%，则 `expect{}` 契约设计过严，须放宽或分层（接 B7）；若连续 3 轮元反审均无发现任何判据缺陷，则元反审本身是冗余开销，应降频。

**工程映射**：v0.1 仅提供基线——两组负对照（`test_no_false_positive`、`test_all_correct_no_replan`）保证「全对不回拆」。本轮另有一次**现场元反审实例**：设计稿的「delta_saving ≥50%」在 T-root 拓扑下不成立，判据被修正为拓扑分档，而非改数据（见 `ACCEPTANCE.md` §拓扑分档）。这是 B12 的真实用例，不是纸面主张。

**置信度**：高（0.80 ± 0.10）。误差来源：样本仅 17 例测试 + 2 个拓扑，需扩到 ≥30 例。

## 5 局限与诚实边界（不得删）

1. v0.1 的 worker 是真值演示函数，未接真实 LLM；「在真实多 agent 集群有效」**未验证**。
2. `delta_saving` 强依赖任务图拓扑；根偏差场景仅 33.3%，不达 50% 理想线。
3. MAST 分类是三大类工程映射，不是 14 子类逐条复刻。
4. B6/B7 未工程化，B3/B12 仅部分工程化，B13 影子沙盘已实现——本文是**主张**，不是验收报告；状态以 README 机制状态表为唯一口径。
5. 所有论文编号经检索核真，较新文献（PreFlect 2602.07187、SagaLLM 2503.11951）仅 abstract 级互证，未读全文。
6. 置信度为主观贝叶斯估计，误差棒为估计区间，非统计置信区间。
7. 本仓已于 2026-11-12 人工授权后推送至 https://github.com/chenhz01/replanweaver；但「已开源」≠「机制已被外部验证」——CI 通过只证明测试与自评器可跑，不证明主张成立。
